# SUM GREATNESS: Build Your Empire

Mobile-first, non-violent 3D business simulation set in San Diego. Players walk or drive through the city, meet NPCs, launch businesses, manage money, acquire property, and learn practical business skills while building an empire.

## Milestone 1 vertical slice

- Mobile-responsive 3D city scene with walking and driving modes
- Mission, business, property, vehicle, learning, and profile panels
- Cash, gems, energy, reputation, XP, and level progression
- NPC conversations and business-learning choices
- Local save system
- Free-to-play storefront placeholders for RevenueCat and AdMob
- Automated build check with GitHub Actions

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
